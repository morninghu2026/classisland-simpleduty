# classisland-simpleduty
通过把每个人的名字变成科目的抽象方法来在ClassIsland里添加值日表。
## 1️⃣简介
一个向ClassIsland里批量添加学号作为科目的脚本。可以不安装插件来实现值日表安排功能，包括临时更换值日生等。

## 3️⃣相比普通的值日表插件的优势
- 轻量，只有几KB。
- 完美利用换课、多周轮换等ClassIsland本身做的非常好的功能。
- 由于核心逻辑都由ClassIsland完成，所以非常稳定。
- 课表与值日表在同一处编辑，更加便捷。
