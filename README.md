# classisland-simpleduty
## 1️⃣简介
一个向ClassIsland里批量添加学号作为科目的.bat脚本。可以不安装插件来实现值日表安排功能，包括临时更换值日生等。项目基本是Vibe Coding，这段文字是纯手写的。

## 3️⃣相比普通的值日表插件的优势
- 轻量，只有几KB。
- 完美利用换课、多周轮换等ClassIsland本身做的非常好的功能。
- 由于核心逻辑都由ClassIsland完成，所以非常稳定。
- 课表与值日表在同一处编辑，更加便捷。
